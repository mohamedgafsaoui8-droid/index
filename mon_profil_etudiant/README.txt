MON PROFIL ETUDIANT — AMIN GAFSAOUI

Fichiers :
- index.html : structure de la page
- style.css : design et responsive
- script.js : menu mobile
- assets/amin-profile.jpg : photo de profil

Pour lancer le projet :
1. Décompressez le dossier.
2. Ouvrez le dossier mon_profil_etudiant dans Visual Studio Code.
3. Ouvrez index.html dans votre navigateur, ou utilisez l'extension Live Server.

Pour personnaliser :
- Modifiez le texte directement dans index.html.
- Modifiez les couleurs et le style dans style.css.
- Remplacez assets/amin-profile.jpg si vous souhaitez changer la photo.

Le site utilise une police Google Fonts avec une police de secours si Internet n'est pas disponible.
